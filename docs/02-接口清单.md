# 接口清单（第一阶段）

所有接口都在 `/api` 下，统一返回：

```jsonc
{ "ok": true, "data": { } }                       // 成功
{ "ok": false, "error": { "message": "…" } }      // 失败（HTTP 4xx/5xx）
```

## 系统与总览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | 服务存活、端口、Node 版本、运行时长 |
| GET | `/api/dashboard?force=1` | 首页汇总：统计卡、项目视图、服务器视图、端口映射、最近日志事件、**生命周期时间线** |
| POST | `/api/dashboard/probe-servers` | 探测"过期"（默认 60 秒）的服务器状态；`{ "force": true }` 全部重测 |

退避规则：连续失败 > 2 次才进入退避，时长 `1min * 2^(failures-3)`，封顶 30 分钟；
采集成功即复位。设置持久化在 `data/monitor.json`，重启工作台自动恢复（`DSM_AUTO_MONITOR_ON_STARTUP=0` 可禁止）。

```jsonc
  "series": {
    "windowMs": 86400000, "from": "…", "to": "…", "count": 3,
    "gaps": [                                   // 采集断档：图上以虚线断开，不连线
      { "from": "2026-10-08T20:00:00.000Z", "to": "2026-10-09T09:00:00.000Z", "ms": 46800000 }
    ],
    "stale": false,                             // 最后一个点太旧 -> true（自动采集可能停了）
    "stats": {                                  // 每项指标独立统计；没采到的是 null，不是 0

    }
  },
  "spikes": [                                   // 尖峰告警（独立于 events.json）
    { "at": "…", "serverId": "srv_x", "serverName": "Demo",
      "metric": "cpu", "value": 96.1, "threshold": 85, "message": "CPU 使用率 96.1%（阈值 85%）" }
```

### 凭据约定

- `authType`: `key` | `agent` | `password`。
- `keyPath` 只保存路径；私钥内容在连接时从磁盘读取，**不入库**。
- `passwordEnv` / `passphraseEnv` 指定环境变量名（默认 `DSM_SSH_PASSWORD_<服务器ID>` / `DSM_SSH_PASSPHRASE_<服务器ID>`），也可写入 `data/secrets.json`（已 gitignore）。
- 请求体中出现 `password`、`passphrase`、`privateKey`、`secret` 等字段时，`POST/PUT /api/servers` 返回 400 并说明原因。

```jsonc
// POST /api/docker/daemon/start（四种返回形态）
{ "launched": true }                                          // 本次真的拉起了
{ "launched": false, "alreadyRunning": true }                  // 引擎本来就能连
{ "launched": false, "alreadyStarting": true }                 // 上一次还在启动中（连点去重）
```

**`origin` 是给前端措辞用的**：`external` 时不能说"已为你拉起"，否则就是抢用户的操作。找不到安装入口返回 400，拉起动作失败返回 502。

## 网盘直链（解析 / 推送 aria2 / 下载到本机）

底层是 `tools/panlink`（Python，零依赖，10 家网盘）。后端只做「起子进程 / 传凭据 / 解析输出」，**不落盘任何 Cookie / Token**。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/pans` | 支持的网盘：`[{ name, requiresAuth, authHint }]`（来自 `pan.py --list-pans --json`） |
| GET | `/api/pans/options` | 页面默认值：`{ downloadDir, aria2Rpc, maxJobs }` |
| POST | `/api/pans/resolve` | 解析分享：`{ url, pan?, pwd?, cookie?, token?, captchaCode?, guest? }` → `{ pan, title, files:[{ path, size, is_dir, url, headers? }] }` |
| POST | `/api/pans/aria2/test` | 探活 aria2：`{ rpcUrl?, secret? }` → `{ url, version, enabledFeatures }` |
| POST | `/api/pans/aria2` | 推送直链：`{ rpcUrl?, secret?, dir?, items:[{ url, path?, headers? }] }` → `{ pushed, failed, results:[{ path, out, ok, gid?, error? }] }` |
| POST | `/api/pans/download` | 新建下载任务：`{ url, pan?, pwd?, cookie?, token?, guest?, dir, jobs?, threads?, noResume?, overwrite?, only? }` → 任务对象。`only` = 只下载这些文件/目录（来自解析结果的 `path`），缺省 = 整条分享 |
| GET | `/api/pans/downloads?limit=10` | 任务列表（按创建时间倒序，最多 50） |
| GET | `/api/pans/downloads/:id` | 单个任务（前端轮询进度用） |
| POST | `/api/pans/downloads/:id/cancel` | 取消（排队中直接出队；运行中杀子进程，**保留 `.part` 以便续传**） |
| POST | `/api/pans/open-dir` | 打开保存目录：`{ dir }`（目录必须已存在） |

**下载任务对象**

```json
{
  "id": "0d5f…", "status": "running", "url": "https://pan.quark.cn/s/xxxx",
  "pan": "夸克网盘", "title": "我的资料", "dir": "D:////Downloads////pan",
  "total": 12, "done": 3, "skipped": 1, "failed": 0,
  "percent": 42.5, "bytesDone": 104857600, "bytesTotal": 246960619,
  "selected": 0,
  "current": "素材/03.mkv",
  "files": [{ "path": "素材/01.zip", "state": "ok" }, { "path": "素材/02.zip", "state": "skipped" }],
  "filesTruncated": false,
  "error": "", "log": ["..."], "createdAt": 1792767000000, "startedAt": 1792767000100, "endedAt": 0
}
```

- `status`：`queued` / `running` / `done` / `error` / `cancelled`。
- **退出码映射**：`pan.py` 返回 0 或 2 → `done`（2 = 部分成功，`failed` 如实保留）；1 → `error` 并提示「参数/前提问题」；3 → `error` 并提示「链接多半失效或需要登录态」。
- **进度口径**：字节进度来自 `pan.py` 的 stderr 进度行（`
` 刷新，无结尾换行也要能解析）；完成数以它最后的「下载完成: 成功 A / 跳过 B / 失败 C」为准，覆盖中途累加值。
- 默认并发 2 个任务（`DSM_PAN_MAX_JOBS`），超出排队；历史最多 20 条（`DSM_PAN_KEEP_JOBS`）；单任务 10 分钟无输出判卡死（`DSM_PAN_INACTIVITY_MS`）。
- **保存目录校验**：必须是绝对路径且带盘符（或 UNC），拒绝盘符根目录与 `C://Windows`，启动前写探针文件确认可写。

**错误语义（可直接展示给用户）**

| 场景 | 状态码 | message 要点 |
| --- | --- | --- |
| aria2 没启动 | 502 | `连不上 aria2（127.0.0.1:6800）… aria2c --enable-rpc=true` |
| 密钥不对 | 400 | `RPC 密钥不对…核对 --rpc-secret`（aria2 用 200 + JSON-RPC error 表示鉴权失败，不是 401） |
| 地址填成网页 | 502 | `返回的不是 JSON…确认地址是 …/jsonrpc` |
| 目录不合法 | 400 | 缺盘符 / 盘符根目录 / 系统目录 / 不可写，各有具体文案 |
| 非 http(s) 直链 | 400 | `第 N 条不是 http/https 直链` |
| 迅雷验证码 | 400 | `需要输入图形验证码`，附 `needsCaptcha: true` 与 `captchaImage`（PNG data URI，可直接 `<img src>`） |

## 本地影院（mediaserver 托管）

后端只做「托管」：`tools/mediaserver` 是纯 Python 标准库实现的本地影音服务（海报墙 + 点开即播 + Real-ESRGAN 超分 + 聚合搜索 + yt-dlp 入库），`services/mediaService.js` 负责拉起 / 停止 / 探活 / 认领 / 打开片库目录 / 日志，运行态由前端 iframe 内嵌影院本体（只听 127.0.0.1）。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/media` | 状态：`{ running, port, url, pid, startedAt, libraryDir, capabilities, adopted }` |
| POST | `/media/start` | 启动（或认领已在运行的实例）：返回同上 + `message`；端口默认 8888，被占顺延；自家实例直接认领 |
| POST | `/media/stop` | 停止：结束整棵进程树并等端口释放，返回 `{ stopped, port, portReleased }` |
| GET | `/media/log?lines=100` | 启动日志尾部（影院 stdout/stderr 全量在 `data/logs/mediaserver.log`） |
| POST | `/media/open-dir` | 打开片库目录（Windows 资源管理器） |

**状态对象 `capabilities`**（来自影院自己的 `/api/list` 与 `/api/dl`，单一事实来源）

```json
{ "upscaler": true, "ffmpeg": true, "ytdlp": false, "ytdlpVersion": null, "videoCount": 12 }
```

- `running`：端口上有 `Server: LocalCinema/2.0` 在响应、或记录过的 PID 还活着。`adopted` = 端口上是别处拉起的实例（你曾双击过 `start.bat`）。
- `libraryDir`：片库目录（`DSM_MEDIA_LIBRARY` / `MEDIA_LIBRARY_DIR` 可覆盖；缺省 `tools/mediaserver/library`）。
- 环境变量 `DSM_MEDIA_DIR`（影院代码目录）、`DSM_MEDIA_PORT`（默认端口）、`DSM_MEDIA_UPSCALER`（超分工具）可覆盖默认。
- 前端探测本机一律 `node:http` 且强制 `Connection: close`，绕过本机代理、避开 keep-alive 复用竞态。

## 约定

- 端口校验：1–65535 的整数，留空表示"未记录端口"（该项目就只能靠进程存活判断运行状态）。
- 时间统一为 ISO 8601（UTC），前端本地化展示。
- `force=1` 会跳过 2.5 秒的端口扫描缓存，强制重新读取系统监听表。
