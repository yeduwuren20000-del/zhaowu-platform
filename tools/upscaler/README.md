# 本地视频 AI 超分 / 修复工具

把模糊的旧视频、低清晰度片源，用你显卡上的 **Real-ESRGAN** 逐帧放大修复成高清，
保留原音轨，输出标准 MP4。**纯本地运行，不联网、不上传、不依赖任何第三方解析接口。**

> 本工具仅用于处理你**自己拥有 / 有权处理**的素材（自拍、家庭录像、老片、你自己购买或获得授权的内容）。
> 请勿用于复制、传播他人享有版权的影视作品。

## 快速开始（Windows）

1. 双击 **`setup.bat`**（首次运行，会自动装 ffmpeg、下载 Real-ESRGAN 引擎，约 45MB）。
2. 双击 **`run.bat`**：
   - 把视频文件**拖进黑窗口**，或粘贴路径回车；
   - 选放大倍数（默认 2）；
   - 选模型（1=通用视频快 / 2=真人实拍 4x 慢）；
   - 等它跑完，输出文件在旁边生成 `原名_upscaled.mp4`。

## 命令行用法

```bat
.venv\Scripts\python.exe upscale.py 输入.mp4 输出.mp4 --scale 2 --model realesr-animevideov3
```

| 参数 | 说明 | 默认 |
|------|------|------|
| `--scale` | 放大倍数 2/3/4 | 2 |
| `--model` | 超分模型（见下表） | realesr-animevideov3 |
| `--gpu` | GPU 编号；`auto` 自动；本机 NVIDIA 是 `1` | 1 |
| `--crf` | x264 画质，越小越清晰，18 接近视觉无损 | 18 |
| `--preset` | x264 速度档 slow/medium/fast | medium |
| `--limit` | 只处理前 N 秒（试效果用，如 `--limit 60`） | 0=整片 |
| `--workdir` | 中间帧目录（默认在输出文件旁；大量临时文件建议指到临时盘） | 输出同级 |
| `--progress` | 写进度 JSON 路径，供外部（如影院）轮询 | 无 |
| `--keep-frames` | 保留中间帧（调试用） | 关 |

### 模型怎么选

| 模型 | 适合 | 速度 | 倍数 |
|------|------|------|------|
| `realesr-animevideov3` | 通用视频（动画/实拍都行） | 快 | 2/3/4 |
| `realesrgan-x4plus` | 真人实拍、细节优先 | 慢 | 固定 4x |
| `realesrgan-x4plus-anime` | 纯动画 | 慢 | 固定 4x |

日常先用 `realesr-animevideov3` + `2x`，效果和速度最平衡。

## 工作原理

```
输入视频 ──ffmpeg 抽帧(PNG无损)──▶ 逐帧 Real-ESRGAN 超分 ──ffmpeg 重编码(H.264)──▶ 成品
                                                    └── 原音轨直通(不损失) ──┘
```

- 引擎：`realesrgan-ncnn-vulkan`，走 **Vulkan**，不需要装 CUDA，N 卡/核显都能用。
  本机（RTX 5060 Laptop 8G）已自动识别并优先使用独显。
- 音轨用 `-c:a copy` 原样封装，不会二次压缩。

## 性能与预期（重要）

- **这是逐帧 AI 计算，很吃时间**。以 1080p 片源跑 2x 为例，RTX 5060 大约每秒处理几帧；
  一段 45 分钟的剧集可能要**几个小时**，属于"睡前挂着跑"的任务。
- 建议：**先剪 1～2 分钟片段**跑一遍，确认效果和耗时，满意再跑整片。
- 中间帧是 PNG，会占较多临时磁盘空间，脚本跑完会自动清理（除非加 `--keep-frames`）。

## 已知限制

- 目前按**恒定帧率(CFR)** 处理；极个别变帧率(VFR)素材可能音画不同步，可先用 ffmpeg 转 CFR 再处理。
- 混合显卡机器上 GPU 编号可能不同；若报错或没用上独显，改 `--gpu auto` 或试 `--gpu 0`。
- 超分不能"无中生有"：极低清、严重噪点/划痕的素材，效果有限，必要时先降噪再超分。

## 目录结构

```

├─ setup.bat          一键初始化（装依赖 + 下引擎）

├─ .venv/             Python 环境（含 imageio-ffmpeg 提供的 ffmpeg）

```
