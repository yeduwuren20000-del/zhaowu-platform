# 本地私人影院 2.0（被 DevServerManager 托管）

一个跑在你自己电脑上的私人影视站。浏览器打开就是海报墙，**点开即播、可拖动进度、边下边播，不用先下载整部片**。
纯 Python 标准库、**只绑定 127.0.0.1**，不联网、不对外、不上传任何东西。

> 本目录是 DevServerManager 的**内嵌副本**：由工作台的「本地影院」页负责一键启动 / 停止 / 探活 / 打开片库目录，
> 运行态整页内嵌到工作台（iframe，只听 127.0.0.1）。你**不需要**手动双击 `start.bat`——
> 想自己单独跑也可以：`python server.py` 或双击 `start.bat`。

## 快速开始（经工作台）

1. 工作台「本地影院」页点 **一键启动**（纯 Python，不需要装依赖）。
2. 点 **打开片库** 把视频文件丢进 `library/` 文件夹（支持 mp4 / mkv / webm / mov / ts / avi 等，含子文件夹）。
3. 刷新页面，海报自动生成，点封面即播。

> 首次带一个 `sample.mp4` 示例（测试图样），可以直接删掉换成你的片源。

## 功能

### 片库（A）
- **自动海报墙**：服务端用 ffmpeg 从视频里抽一帧当封面，缓存在 `.cache/thumbs/`。
  想指定封面？在视频旁边放一张**同名** `.jpg` / `.png`（如 `电影.mp4` + `电影.jpg`），优先用它。
- **播放进度记忆**：每 5 秒记一次位置，存在 `.cache/progress.json`，关掉浏览器再打开也能续播。
- **继续观看**：没看完的片（>20 秒、进度在 3 秒~97% 之间）自动排在最上面，直接点就跳回上次位置。
- **流式播放**：`/api/stream` 支持 HTTP Range → 拖动进度条、边下边播，不整档下载。
- **已修复标记**：`library/_已修复/` 里的片子会打上 `HD 已修复` 角标。

### AI 修复（B）
片库卡片上悬停 → 点 **⚡ AI 修复**，选倍数 / 模型 / 范围，后台就跑起来了：

| 选项 | 说明 |
|------|------|
| 2x / 3x / 4x | 放大倍数（实拍模型是固定 4x） |
| 通用 / 快速 | `realesr-animevideov3`，最快，动画、字幕、真人都能用 |
| 实拍 / 高质 | `realesrgan-x4plus`，明显更慢但细节更好 |
| 先试 60 秒 / 前 5 分钟 / 整片 | **强烈建议先试 60 秒**，确认效果再整片跑 |

- 进度条 + 帧数 + 预计剩余时间实时刷新（可关页面，任务在后台继续）。
- 成品自动落到 `library/_已修复/`，完成后片库自动刷新，直接就能播。
- 中间帧写在系统临时目录，**不会污染片库**，跑完自动删。
- 超分引擎在 `../upscaler`（与影院一起收进工作台的 `tools/`）：含 Real-ESRGAN 模型与 venv。

### 下载入库（yt-dlp）
「下载入库」页 = 把**公开视频**抓下来直接进片库（B站 / YouTube / 公开课程 / 直链 mp4 都行）：

- 一行一个链接，一次最多 20 个；同时最多跑 **2 个**下载（排队，不会互相抢带宽）；
- 画质：**最高画质**（默认）/ ≤2160p / ≤1080p / ≤720p / ≤480p / 仅音频 MP3；
- 分辨率优先，**同分辨率优先 H.264**（`-S res,vcodec:h264`）——浏览器、电视盒子都能直接播；
- 进度实时显示百分比、总大小、速度、剩余时间，支持**停止**（连子进程一起收）；
- 成品落在 `library/`，播完自动出现在片库（海报、续播一并可用）。

> 它只下载你粘贴的公开链接，不做任何平台签名绕过、不解密付费内容。
> 缺 yt-dlp 时一行装好：`..\upscaler\.venv\Scripts\python.exe -m pip install -U yt-dlp`

### 在线播放
切到「在线播放」页，粘贴 mp4/webm 直链或 `.m3u8` 地址直接播（HLS 走 hls.js，本地 `static/hls.min.js` 优先，没网也能用）。
这里只播放你提供的地址，**不内置任何第三方解析接口**。

### 画质（默认最高）
播放器右上角有「画质」按钮，**默认锁定最高档**，不需要每次手动选；想省流量可选「自动（自适应）」。

### 聚合搜索（全网搜片）
「聚合搜索」页 = 一个多源聚合器，接口格式是 **Apple CMS V10**：

```
搜索：https://你的源/api.php/provide/vod/?ac=videolist&wd=关键词
详情：https://你的源/api.php/provide/vod/?ac=videolist&ids=视频ID
```

**这个工具不预置任何采集源**——展开「采集源管理」自己填接口地址，点「测试并添加」验证连通后即可用。

- **并行搜索**：所有启用的源同时打，单源 8 秒超时，挂掉的源只丢弃自己不拖累整体；
- **跨源合并**：同名同年份的片合并成一张卡，卡片上显示「N 个源可用」，取不到剧集会自动换下一个源；
- **m3u8 代理 + 改写**：`/api/agg/proxy` 把分片、`EXT-X-KEY` 地址都改成走本机，绕开跨域限制；
- **SSRF 防护**：代理只放行公网 http/https，内网/回环/保留地址在 DNS 解析后再校验并拒绝。

> 源的内容合法性由对应站点负责，本工具只是客户端。私人自用即可，别对外提供服务。

### 从 LibreTV / TVBOX 批量导入源
「采集源管理」里展开 **“从 LibreTV / TVBOX 配置批量导入源”**，三种输入都吃：LibreTV-SourceList、TVBOX 配置（`sites` + `type` 0/1/4）、纯文本一行一个地址。

## 目录结构

```
tools/mediaserver/
├─ start.bat      双击启动（也可经工作台托管）
├─ server.py      本地服务器（标准库，无依赖）
├─ agg.py         聚合搜索：多源并行/合并、m3u8 代理改写、SSRF 防护、源清单导入
├─ dl.py          yt-dlp 下载器：公开视频抓进片库，进度回传
├─ index.html     海报墙 + 播放器 + 聚合搜索 + 下载入库 + 修复面板
├─ static/        本地 hls.js（离线可用）
├─ sources.json   你填的采集源（不预置内容）
├─ library/       放你的视频（含子文件夹会自动扫描）
│   └─ _已修复/   AI 修复的成品自动放这里
└─ .cache/        缩略图、观看进度、任务进度（可随时删，会自动重建）

../upscaler/       超分引擎（Real-ESRGAN 模型 + venv），AI 修复依赖它
```

## 环境变量（托管 / 单独跑都生效）

| 变量 | 作用 | 默认值 |
|------|------|--------|
| `PORT` | 监听端口 | `8888`（工作台托管时若被占会自动顺延） |
| `MEDIA_LIBRARY_DIR` | 片库目录（绝对路径） | `<mediaserver>/library` |
| `MEDIA_UPSCALER_DIR` | 超分工具目录 | `<mediaserver>/../upscaler` |

工作台还可用 `DSM_MEDIA_DIR` / `DSM_MEDIA_PORT` / `DSM_MEDIA_LIBRARY` / `DSM_MEDIA_UPSCALER` 在**不改动本目录**的情况下覆盖上述默认值。

## 安全说明

- 仅监听 `127.0.0.1`；不会开放到局域网/公网。
- 播放前做路径校验，`library/` 之外的文件无法被访问（防目录穿越）。
- 工作台托管时，能力标志（AI 修复 / 海报 / yt-dlp）以影院自己的 `/api/list`、`/api/dl` 返回为准，单一事实来源。

## 私人自用提醒

处理你自己有权处置的素材（家庭录像、老片、你买过的内容）没问题；
别录屏搬运再对外分发，那条线一踩就变成侵权。聚合搜索 / 下载入库同理——只当客户端用，别对外开服务。
